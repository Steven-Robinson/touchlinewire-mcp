Frequently Asked Questions

Do I need an API key or account to use Touchline Wire MCP or REST endpoints?

No. Both the Remote Streamable HTTP MCP server (https://touchlinewire.com/mcp) and the public REST API (https://touchlinewire.com/api/v1/*) are 100% free and unauthenticated under the MIT license with attribution.

Which football season powers the Touchline Wire feeds?

All endpoints serve live current-season 2026/27 Premier League squads, verified 2026/27 head coaches, official standings, PGMOL referee appointments, and Fantasy Premier League telemetry.

Can I call the REST API directly without MCP?

Yes. Import the OpenAPI 3.0 Specification into Postman, Insomnia, Python, TypeScript, or OpenAI Custom GPT Actions, or browse live examples in the Interactive REST API & MCP Docs.
